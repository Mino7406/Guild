# 몬헌 레이드(퀘스트) 설계서

작성일 2026-11-08 · 상태: **1단계 구현 중**

> 표기: **[결정]** 사용자가 정한 것 · **[제안]** Claude 안(사용자가 "일단 ㄱ"으로 진행 승인) · **[미정]** 나중에 정할 것

Arcade_BOT의 `/레이드`에서 **큰 틀만** 가져온다(출현 → 모집 → 턴제 전투 → 결과, V2 패널 그림, 동시 클릭 처리, 재시작 이어가기, 묻힘 방지).
역할·행동·몬스터·보상 같은 세부는 전부 몬헌식으로 새로 만든다. [결정]

---

## 1. 큰 흐름

| 항목 | 내용 |
|---|---|
| 시작 | `/퀘스트`로 몬스터를 골라 모집을 연다. 자동 출현 등은 다 만든 뒤 다시 정한다. [결정] |
| 인원 | 1~4명. 인원에 맞춰 몬스터 체력을 조절한다. [결정] |
| 참가 | `/장비`에서 미리 정한 장비(무기 종류·무기·속성·방어구)로 "참가" 버튼 한 번에 참가한다. [결정] |
| 장비 변경 | 모집 화면의 "장비" 버튼 → 본인만 보는 장비 창. 전투 시작 전까지 바꿀 수 있다. [결정] |
| 전투 | 턴제. 몬스터가 다음 행동을 예고 → 각자 부위·행동 선택 → 한꺼번에 처리. [결정] |
| 실패 | 파티 합계 3번 쓰러지면 실패(수레 3회), 또는 제한 시간 초과. [결정] |
| 보상 | 소재(도감 소재표 확률) + 헌터 랭크(HR). 소재로 장비 제작. [결정] |
| 난이도 | 몬스터마다 하나로 고정(하위/상위 구분 없음). 소재는 상위 소재표를 쓴다. [결정] |
| 화면 | 몬스터 아이콘 이미지로 패널 PNG를 그린다(HP·부위·파티 상태). [결정] |

빼는 것: 아이템·함정·섬광·포획(이번엔 안 함). [결정]

## 2. 턴

1. 몬스터가 다음 행동을 예고한다(대상: 한 명 / 전원 / 없음).
2. 각자 고른다.
   - **노릴 부위**: 선택 메뉴(머리·몸통·날개·꼬리…). 한 번 고르면 바꿀 때까지 유지.
   - **행동**: 공격 · 무기 기술 · 회피(가드 무기는 가드) · 회복약
3. 모두 고르거나 제한 시간이 끝나면(못 고른 사람은 공격) 결과를 처리하고 패널을 다시 그린다.

## 3. 피해 계산 [제안]

몬헌 공식을 단순화한다.

```
물리 = 무기 공격력 × 기술 배율 × (그 부위 육질[절단|타격|탄] / 100)
속성 = 무기 속성값 × (그 부위 속성 육질 / 100)
피해 = (물리 + 속성) × 분노·버프 등 보정
```

- 육질·속성 육질은 도감 데이터(키라니코) 그대로. → 머리를 노리면 확실히 아프다.
- **부위 내구도**(키라니코 부위 HP)를 깎으면 **부위 파괴** → 파괴 보수 소재.
- **기절**: 타격 무기로 머리를 치면 누적. **상태이상**(독·마비·수면·폭파): 상태이상 무기가 누적, 내성은 도감 값.
- **분노**: 체력 일정 이하 또는 일정 턴마다 → 몬스터 피해 증가, 행동 변화.

## 4. 무기 14종 [제안]

무기마다 "무기 기술" 하나가 고유 메커니즘이다.

| 무기 | 피해 유형 | 무기 기술 |
|---|---|---|
| 대검 | 절단 | 모아베기 — 한 턴 모으고 다음 턴 큰 한 방 |
| 태도 | 절단 | 기인 게이지 — 칠수록 차고, 가득 차면 기인 큰베기 |
| 한손검 | 절단 | 가드 + 아이템을 쓰면서 공격 |
| 쌍검 | 절단 | 귀인화 — 몇 턴 연타 피해 증가, 회피 불가 |
| 해머 | 타격 | 머리 타격 시 기절 누적 큼 |
| 수렵피리 | 타격 | 연주 — 파티 전체 버프 |
| 랜스 | 절단 | 가드 특화 — 막으면 반격 |
| 건랜스 | 절단 | 포격 — 육질 무시 고정 피해, 용격포 |
| 슬래시액스 | 절단 | 도끼↔검 변형, 검 모드 속성 해방 |
| 차지액스 | 절단 | 병 충전 → 초고출력 해방 |
| 조충곤 | 절단 | 엑기스 3색 수집 → 강화 |
| 라이트보우건 | 탄 | 속사, 속성·상태이상탄 |
| 헤비보우건 | 탄 | 고화력 저격, 다음 턴 회피 불가 |
| 활 | 탄 | 차지 단계에 따라 피해 증가 |

## 5. 몬스터

- 처음 고유 패턴: **레 다우 · 리오레우스 · 알슈베르도 · 고어 마가라** (간판·인기). [결정]
- 몬스터 수치(육질·부위·속성 약점·상태이상 내성)는 도감 JSON + 키라니코 부위 내구도에서 가져온다.
- 기술·기믹·예고 문구는 몬스터마다 손으로 만든다(`raid/monsters/*.json`). [제안]

## 6. 장비·성장 [제안]

- 처음엔 모두 무기 14종 기본 무기 + 기본 방어구를 가진다.
- 첫 4마리마다 무기 계열(속성 포함)과 방어구 한 벌 → 해당 몬스터 소재로 제작.
- HR: 토벌할 때마다 HR 포인트 → HR. HR 제한 퀘스트는 [미정].

## 7. 저장

- 헌터 정보(장비·소재함·HR)와 진행 중 퀘스트를 서버 파일로 저장한다(봇 재시작에도 유지). 형식은 구현 판단.

## 8. 단계

1. **1단계**: 저장소, `/장비`, `/퀘스트` 모집(참가·장비 버튼), 턴제 전투 기본(무기 14종 기본 공격, 부위·육질 피해, 수레 3회, 분노 기본), 레 다우 한 마리, 소재 보상
2. **2단계**: 무기 기술 14종, 상태이상·기절·부위 파괴 보상, 나머지 간판 3마리
3. **3단계**: 장비 제작, HR, 패널 그림 다듬기, 시작 방식(자동 출현 등) 재검토
